`git rebase --onto v0.1.40.3 v0.1.40.2 pla-0142`. Production stays

`git range-diff v0.1.40.2..pla-0142 v0.1.40.3..pla-0143` shows all 53 commits
identical, and `git diff pla-0142 pla-0143` is byte-equal to `git diff v0.1.40.2 v0.1.40.3`

conflict surgery to occur; there were no conflicts.

diagnostics, the native-router guard `n_expert == 512 && K == 10` (mtp drafter, #1357,

## Traps hit (mine, recorded so nobody rebuilds them)

- The exact/nospec compose overlay must differ from spec exactly like 0142's
  (nospec: `STRATA_PIPELINE_THETA=2`, no `DECODE_TIMING`). Writing it identical to spec
  turns the gate into spec-vs-itself and measures run-to-run drift under PLA traffic.
- Mount the engine config rw: setup.py `cfg_path.touch()` dies with Errno 30 on `:ro`
  (the base compose already comments this).
- The per-container vision helper recompile (2-4 min at first start of
  a new image+config, into the container layer) is normal - not a failure.
- Never `docker compose up` a second engine during a gate window: 2x ~47 GB on the 59 GB LXC
  is freeze territory. The verify scripts always restore prod via their EXIT trap.

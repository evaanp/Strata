- `--batch-groups` auto on a layer split: one group per GPU stage as a pipeline
  (ca001df5; 2 GPUs measured by upstream 109 vs 78 total tok/s,
  4xR9700 166 vs 86). `--batch-groups 1` = old behaviour.

  left alone returns to the solo path with its drafts.
- `--batch-mtp` is still one-GPU-only (generate.cpp:3873-3874: "for one GPU
  (no layer split or helper) for now").
- Batch windows still zero penalties (`verify.cpp:2774`); prod uses
  presence_penalty 0, so not a blocker.
- `--peer-device` gained a no-P2P mapped-host route (81af1da0, 59ea77e5; test
  knob `STRATA_PEER_NO_P2P=1`, b92a44bf) - the helper-GPU route that died on
  P2P on 2026-10-04 becomes measurable.
- `STRATA_STAGE_PIN` default OFF: on by default it corrupted IQ3_S decode
  after a long prompt in upstream's own release gate (fb58e0db). Prod quant is
  IQ3_S: do not enable it.

## Box window plan (the speedups agreed 2026-10-08)

The window cost is engine loads, not the gates. Full engine ~47 GB;
the 59 GB LXC never holds two. So:

1. **Goldens first, from prod, no control engine later.** Prod IS
   the reference (0.1.40.3-pla1). Run the parity tool's fixed request set
   against `:8080` with its own conversation ids, `--min-free-mib 256`,
   in a quiet period (capacity pressure during capture would make
   parking behaviour differ from the quiet replay window). Save outputs as goldens.
   A lone-message curl is NOT the protocol: PLA sends full history every turn;
   a single-message client makes the engine fork at the first divergence
   (`does not continue its live end: diverges at N of M`).
2. **One engine load per window.** Stop prod -> start candidate
   (`:8081`, image `strata:0.1.41-pla1`) -> run ALL gates against that same
   live engine: parity x3 vs the goldens (byte-exact, same `--min-free-mib`
   both sides), exact-identity battery, then one smoke bench run (skip the full
   5-run bench: parity byte-exact is the stronger check; bench stays smoke).
3. Stop candidate -> prod back (fallback compose as before).
   Total engine loads: 2, not per gate.
4. **Image must carry the 0143 vision fix**: the COPY overlay copies `tools/`
   (upstream changed tools/vision) -> `vision_src` stamp mismatch -> ~7 min vision
   compile per fresh container. Bake `strata-vision` + corrected `engine/BUILD.json`
   into the 0141 image the same way as `enginefix/` in 0143.
5. PLA must not bell `:8081` and the capture/replay windows stay clear of PLA
   traffic on the engine under test (`beurt` retries on `:8080`
   contaminated the first identity run in 0142).

Residual correctness risk after dev gates: only the semantic class -
`park_view` x evict loop, stage-lend x new foresight swap, our protect x
upstream pin. Parity x3 vs goldens + identity battery are exactly the gates
that see that class. Upstream's own release gates covered their code
(themselves caught the IQ3_S stage-pin corruption).
